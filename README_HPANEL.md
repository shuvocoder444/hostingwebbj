# 🚀 VeloHoster Custom "hPanel" Architecture & Step-by-Step Implementation Roadmap

> **উদ্দেশ্য:** cPanel/WHM Reseller হোস্টিং ব্যাকএন্ডে রেখে ক্লায়েন্টদের জন্য Hostinger-এর মতো একটি আধুনিক, ব্র্যান্ডেড এবং সম্পূর্ণ কাস্টম **"hPanel" (Control Panel)** তৈরি করা। ক্লায়েন্ট কখনো cPanel-এর জটিল ইন্টারফেস দেখবে না, বরং VeloHoster ড্যাশবোর্ড থেকেই ১-ক্লিকে ওয়েবসাইট, ইমেইল, ডাটাবেস ও ফাইল ম্যানেজ করতে পারবে।

---

## 📌 ১. সিস্টেম আর্কিটেকচার (System Architecture)

```
┌────────────────────────────────────────────────────────┐
│             VeloHoster Web Platform (Django 5)         │
│           (Tailwind CSS + FontAwesome + Alpine.js)     │
└──────────────────────────┬─────────────────────────────┘
                           │
             ┌─────────────┴─────────────┐
             ▼                           ▼
┌─────────────────────────┐ ┌─────────────────────────┐
│     Classic cPanel      │ │     Velo "hPanel"       │
│    (Direct Port 2083)   │ │  (Custom In-App Suite)  │
│  - cPanel Raw Access    │ │  - Modern Cards & Tools │
│  - User manages cPanel  │ │  - 1-Click Direct SSO   │
└─────────────────────────┘ └────────────┬────────────┘
                                         │ cPanel UAPI v3
                                         │ & WHM API v1
                                         ▼
┌────────────────────────────────────────────────────────┐
│           WHM / cPanel Server Backend (Linux)          │
│   (Account Provisioning, MySQL, Exim Mail, Apache)     │
└────────────────────────────────────────────────────────┘
```

|---|---|---|---|
| **Standard cPanel Plan** | ৫টি অ্যাকাউন্ট | ১.২ GB প্রতিটি (মোট ৬ GB) | ক্লায়েন্টকে ডিরেক্ট cPanel লিঙ্ক ও ক্রেডেনশিয়াল দেওয়া হবে। |

## 📋 ৩. স্টেপ-বাই-স্টেপ ইমপ্লিমেন্টেশন রোডম্যাপ (Implementation Phases)

### 🔹 ধাপ ১: cPanel UAPI কমিউনিকেশন ড্রাইভার তৈরি (`hosting/cpanel_uapi.py`)
- [ ] **UAPI কোর ইঞ্জিন তৈরি:** cPanel ইউজার সেশনের মাধ্যমে UAPI মেথড কল করার নিরাপদ ড্রাইভার।
- [ ] **Security Token & SSO জেনারেটর:** `create_user_session` API-র মাধ্যমে ১-ক্লিক ডিরেক্ট লগইন ইউআরএল তৈরি (ইউজারকে ম্যানুয়ালি পাসওয়ার্ড দিতে হবে না)।
- [ ] সার্ভিস ভিত্তিক টোকেন ক্যাশিং এবং ফেইলওভার হ্যান্ডলিং।

### 🔹 ধাপ ২: ক্লায়েন্ট "hPanel" ড্যাশবোর্ড ইন্টারফেস (`templates/hosting/hpanel.html`)
- [ ] Hostinger-এর মতো প্রিমিয়াম কার্ড-বেসড গ্রিড লেআউট ডিজাইন।
- [ ] রিয়েল-টাইম রিসোর্স ইউজেজ উইজেট (ডিস্ক স্পেস ব্যবহার, ব্যান্ডউইথ, আইনোডস)।
- [ ] সার্ভিসের মূল তথ্য (ডোমেন, আইপি, নেমসার্ভার, পিএইচপি ভার্সন, এসএসএল স্ট্যাটাস)।
- [ ] কুইক অ্যাকশন বাটন:
  - ⚡ **Open cPanel (SSO)**
  - 🗄️ **Open phpMyAdmin (SSO)**
  - ✉️ **Open Webmail (SSO)**
  - 📁 **Open File Manager (SSO)**

### 🔹 ধাপ ৩: কর্পোরেট ইমেইল অ্যাকাউন্ট ম্যানেজার (Business Email Suite)
- [ ] ইমেইল অ্যাকাউন্ট লিস্ট ফেচ করা (`Email::list_pops_with_disk`).
- [ ] VeloHoster ড্যাশবোর্ড থেকেই নতুন কাস্টম ইমেইল তৈরি (`Email::add_pop` - যেমন: `support@domain.com`).
- [ ] ইমেইল কোটা (Storage Limit) বাড়ানো বা কমানো।
- [ ] ইমেইলের পাসওয়ার্ড রিসেট করা।
- [ ] ১-ক্লিক **Launch Webmail SSO** (পাসওয়ার্ড ছাড়াই সরাসরি Roundcube ওয়েবমেইলে লগইন)।
- [ ] অপ্রয়োজনীয় ইমেইল অ্যাকাউন্ট ডিলিট করার ব্যবস্থা।

### 🔹 ধাপ ৪: ডাটাবেস ও phpMyAdmin ম্যানেজার (MySQL Database Suite)
- [ ] বিদ্যমান ডাটাবেস ও ডাটাবেস ইউজারের তালিকা প্রদর্শন (`Mysql::get_server_information`).
- [ ] নতুন ডাটাবেস ও ইউজার তৈরি করার ফর্ম (`Mysql::create_database`, `Mysql::create_user`).
- [ ] ডাটাবেসে ইউজারকে সম্পূর্ণ পারমিশন (ALL PRIVILEGES) অ্যাসাইন করা।
- [ ] ডাটাবেস ইউজারের পাসওয়ার্ড পরিবর্তন।
- [ ] ডাটাবেস ড্রপ/ডিলিট করা।
- [ ] ১-ক্লিকে **phpMyAdmin SSO** ওপেন করার সরাসরি বাটন।

### 🔹 ধাপ ৫: ফাইল ম্যানেজার ও এফটিপি অ্যাকাউন্টস (File & FTP Suite)
- [ ] এফটিপি (FTP) অ্যাকাউন্ট তালিকা ও নতুন FTP অ্যাকাউন্ট তৈরি (`Ftp::add_ftp`).
- [ ] এফটিপি কানেকশন ক্রেডেনশিয়াল (Host, Username, Port: 21) দেখানো।
- [ ] ১-ক্লিক **cPanel File Manager SSO** ডিরেক্ট লিঙ্কিং।

### 🔹 ধাপ ৬: ডোমেন, সাবডোমেন ও ডিএনএস ম্যানেজার (Domains & DNS)
- [ ] সাবডোমেন তৈরি ও ম্যানেজ করা (`SubDomain::addsubdomain` - যেমন: `blog.domain.com`).
- [ ] জোন এডিটর (DNS Zone Management):
  - A Record, CNAME, MX Record, TXT (SPF/DKIM) দেখা এবং যোগ করা।
- [ ] ফ্রি SSL সার্টিফিকেট স্ট্যাটাস ও ১-ক্লিকে **Let's Encrypt / cPanel AutoSSL** ট্রিগার।

### 🔹 ধাপ ৭: প্যাকেজ কনফিগারেশন ও অ্যাডমিন সুইচ (Admin Integration)
- [ ] `HostingPackage` মডেলে নতুন ফিল্ড যোগ: `control_panel_type` (`cpanel` বনাম `hpanel`).
- [ ] প্যাকেজ অনুযায়ী ক্লায়েন্ট পোর্টালে ইন্টারফেস নির্বাচন:
  - ক্লাসিক cPanel প্যাকেজ হলে সাধারণ ডিটেইলস পেজ দেখাবে।
  - hPanel প্যাকেজ হলে সম্পূর্ণ আধুনিক কাস্টম hPanel কন্ট্রোল প্যানেল লোড হবে।

### 🔹 ধাপ ৮: লোকাল টেস্টিং, ভ্যালিডেশন ও লাইভ সার্ভারে ডিপ্লয়মেন্ট
- [ ] লোকাল ডাটাবেজ ও কোড ভ্যালিডেশন (`python manage.py check`).
- [ ] লাইভ সার্ভারে (`velohoster.com`) ডিপ্লয়মেন্ট।
- [ ] লাইভ cPanel অ্যাকাউন্টে ইমেইল, ডাটাবেস ও SSO এক্সেস টেস্ট করা।
